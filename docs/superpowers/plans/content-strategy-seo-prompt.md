## SEO KEYWORD STRATEGY

### Primary keyword patterns to hit in EVERY post:
- `[wine/spirit] Bangkok` — local intent (highest conversion)
- `[wine/spirit] Thailand` — national intent
- `buy [wine] in Bangkok` — transactional
- `[wine] price Thailand` — comparison shoppers
- `best [wine] under ฿[X]` — price-anchored (very high conversion)

### AEO (Answer Engine Optimization) — Required FAQ in every post:
Each post must include 3–5 H3 FAQ questions that answer exactly how someone asks ChatGPT or Google:
- "Where can I buy [wine] in Bangkok?"
- "How much does [wine] cost in Thailand?"
- "What's the difference between [A] and [B]?"
- "Is [wine] available in Thailand?"
- "Can I get [wine] delivered in Bangkok?"

### Premium collector keywords (high value, low competition):
- `[specific wine name] price Thailand` — e.g. "Chateau Margaux price Thailand"
- `[wine name] Bangkok buy online` — transactional, collector
- `[wine name] vintage [year] Thailand` — specific vintage hunters

## CONTENT QUALITY STANDARDS

### Voice & Tone
- **Knowledgeable sommelier friend**, not a textbook
- Direct, no filler. Think Monocle × Decanter written for Bangkok traffic
- English body. Thai dish names / place names in Thai script are fine: *ส้มตำ, ต้มยำ, ข้าวมันไก่*
- NEVER: "In conclusion," "In this article we will," "as we have seen"
- NEVER: pad with generic wine history not relevant to Thailand market

### Structure (required every post)
1. **Hook intro** — 2–3 sentences, lead with the reader's problem or Bangkok context
2. **H2 sections** — 3–6 sections with distinct visual break
3. **Product embeds** — minimum 3 per post; premium/high-reputation SKUs first
4. **Section images** — 1 per H2, thematically accurate (see Image Rules)
5. **FAQ section** — 3–5 H3 questions, required every time (AEO)
6. **No CTA section needed** — product embeds ARE the CTA

## IMAGE RULES (non-negotiable from prior session)

### Requirements
1. Subject must match the section topic **exactly** — white wine section = white wine glass, NOT red wine
2. Free-tier Unsplash only — URL must start with `images.unsplash.com/photo-` (NOT `plus.unsplash.com/premium_photo-`)
3. CDN ID format: 13-digit numeric + 12-char hex (e.g. `1682071308366-1d098905b498`)
4. Verify each ID: `curl -s "https://images.unsplash.com/photo-{ID}?w=100" -o /dev/null -w "%{http_code}"` → must return 200
5. Caption = 1-sentence editorial description. NO "Photo by X on Unsplash" credits.

### How to find free-tier IDs
```bash
# Get free-tier IDs from Unsplash search
curl -sL "https://unsplash.com/s/photos/[search-term]" | grep -o 'images\.unsplash\.com/photo-[0-9]\{13\}-[a-f0-9]\{12\}' | sort -u | head -10

# Verify each returns 200
curl -s "https://images.unsplash.com/photo-{ID}?w=200" -o /dev/null -w "%{http_code} %{content_type} %{size_download}\n"
```
